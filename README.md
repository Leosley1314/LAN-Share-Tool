# 局域网共享工具 (LAN Share Tool)

Windows 一键配置局域网共享，支持磁盘/文件夹/打印机共享。

## 功能
- 图形界面（GUI），无需命令行
- 选择磁盘或自定义文件夹共享
- 一键共享所有非 C 盘磁盘
- 取消所有共享（关闭 SMB1 + 停止 Server 服务）
- 无密码访客访问 / 指定用户名密码
- 网络发现开关
- 只读 / 读写权限
- 打印机共享开关
- 查看当前共享状态
- 一键重启资源管理器
- 选项悬停提示
- 免责协议确认
- 完成后显示 Windows / 手机访问地址
- 自动启用 SMB1（注册表 + DISM）
- 自动配置防火墙（专用/公用网络均放行）
- 自动启动所需系统服务

## 兼容性
- Windows Vista / 7 / 8 / 8.1 / 10 / 11
- PowerShell 2.0+

## 使用
双击 `局域网共享工具.exe`，选择共享内容后点"开始配置"。
