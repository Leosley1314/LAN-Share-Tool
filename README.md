# 局域网共享工具 (LAN Share Tool)

Windows 一键配置局域网共享，支持磁盘/文件夹/打印机共享。

## 功能
- 图形界面（GUI），无需命令行
- 选择磁盘或自定义文件夹共享
- 一键共享所有非 C 盘磁盘
- 取消所有共享（还原默认）
- 无密码访客访问开关
- 网络发现开关
- 打印机共享开关

## 兼容性
- Windows Vista / 7 / 8 / 10 / 11
- PowerShell 2.0+

## 使用
双击 `局域网共享工具.exe`，选择共享内容后点"开始配置"。
